# SaaS Dashboard

Dashboard interaktif dengan table data kompleks: pencarian real time, filter status, kalkulasi total harga, dan penambahan data lewat modal form. Responsif di mobile, tablet, dan desktop.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS v4 
- Poppins (Google Fonts)
- EsLint 10 (flat config)

## Prerequisites

- Node.js >= 20.19
- npm >= 10

## Local Setup

```bash
git clone https://github.com/zianscode/saas-dashboard.git
```
```bash
cd saas-dashboard
```
```bash
npm install
```
```bash
npm run dev
```
